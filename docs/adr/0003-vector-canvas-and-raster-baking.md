# 벡터 주석 캔버스와 래스터 산출물 합성(Baking) 분리

## Context
캡처 후 화살표, 텍스트, 사각형, 모자이크를 편집할 때 원본 캡처 비트맵을 직접 파괴적으로 수정(픽셀 덮어쓰기)하면 실행 취소(Undo, `Ctrl+Z`)나 도형 위치 재조정이 불가능해집니다.

## Decision
사용자 상호작용 단계에서는 원본 비트맵 배경 위에 WPF `Canvas`를 벡터 레이어로 유지하여 비파괴적(Non-destructive)으로 주석 객체를 관리하고, `Enter` 또는 복사/저장 완료 이벤트 발생 시에만 `RenderTargetBitmap`을 통해 원본 비트맵과 주석 레이어를 단일 `CaptureOutput` 비트맵으로 일괄 합성(Baking)합니다.

## Consequences
- `Ctrl+Z` 실행 취소 스택과 주석 요소 재편집을 단순한 객체 컬렉션 조작(`UIElementCollection`)으로 처리할 수 있습니다.
- 최종 출력 시 1회의 합성 렌더링만 수행하므로 편집 도중 불필요한 비트맵 인코딩/디코딩 오버헤드가 발생하지 않습니다.
