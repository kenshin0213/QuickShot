# GDI BitBlt 기반 정적 가상 화면 덤프 및 단일 전역 오버레이 채택

## Context
다중 모니터 환경은 서로 다른 해상도, 음수 좌표(주 모니터 좌측/상단 배치), 서로 다른 DPI 배율(100%, 150% 등)이 혼재합니다. 모니터별로 개별 오버레이 윈도우를 띄울 경우 모니터 경계를 가로지르는 드래그 캡처 시 마우스 캡처 유실과 좌표 불연속 결함이 발생합니다.

## Decision
Win32 GDI `BitBlt`를 사용하여 전체 가상 화면(`SystemParameters.VirtualScreen`)의 디바이스 컨텍스트(DC)를 단일 래스터 비트맵으로 덤프하여 즉시 프리징하고, 가상 스크린 전체를 덮는 단일 테두리 없는 Topmost WPF 창(`VirtualCanvas`)을 오버레이로 사용합니다.

## Consequences
- Windows.Graphics.Capture API 대비 비디오 프레임 스트리밍 보일러플레이트 없이 초저지연 정적 스냅샷을 생성할 수 있습니다.
- 단일 윈도우 좌표계를 사용하므로 모니터 경계를 넘나드는 대각선 드래그 선택 및 리사이즈 조작 시 마우스 이벤트가 끊김 없이 보장됩니다.
