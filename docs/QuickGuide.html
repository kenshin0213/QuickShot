QUICKSHOT 초간단 5초 가이드

어린이도 바로 쓰는 QuickShot

글 읽지 말고 딱 4단계만 기억하세요!

1

[호출] 상단에 모드 메뉴가 떠요!

언제 어디서든 키보드에서 단축키 3개를 동시에 딱 누르세요.

Ctrl + Shift + A
직사각형 창 감지 현재 화면 모든 화면 (4대 모니터)
2

[선택] 창 클릭 또는 드래그!

원하는 창을 콕 찍거나 네모를 그리면, 이미 복사 완료!

[클릭 1회로 창 캡처 / 자동 복사]

카톡, 슬랙, 메모장에 바로 Ctrl + V 붙여넣기!

3

[주석] 글자 & 모자이크로 꾸며요!

하단 툴바에서 글자크기(12~40pt)와 모자이크로 개인정보를 가려요.

텍스트 (12~40pt) 모자이크 화살표 형광펜

편집 중 복사: Ctrl + C (창 유지)

4

[완료] 엔터 치면 저장까지 완료!

꾸미기가 끝났으면 엔터를 탁 치세요. 수정본이 다시 복사되고 파일도 저장돼요.

Enter

내 사진/QuickShot 폴더에 자동 보관됩니다!

[단축키 모음] 초고속 조작 일람표

창 캡처

모든 모니터 전체 캡처 (4대 통째로)
상단 바 모든 화면 또는 트레이 우클릭

Ctrl + C

Enter
