# QuickShot 사용자 설명서 (User Manual)

Windows 10/11 환경을 위한 고속 화면 캡처 및 즉석 주석 도구 **QuickShot**의 정식 종합 사용자 매뉴얼입니다.

---

## 1. 개요 및 핵심 아키텍처

### 1.1 프로그램 소개
QuickShot은 일상 업무, 개발, 디자인, 원격 협업 중 필요한 화면을 지연 없이 즉시 캡처하고, 핵심 영역 강조와 민감 정보(개인정보, 계좌번호, 비밀번호 등)의 모자이크 처리를 별도 창 이동 없이 한 화면에서 완결할 수 있도록 설계된 초고속 캡처 유틸리티입니다.

### 1.2 핵심 아키텍처 및 특징
1. **무설치 단일 파일 실행 (Self-Contained)**:
   * 복잡한 설치 마법사나 외부 .NET 런타임 설치 없이 [publish/QuickShot.exe](file:///d:/Workspace/QuickShot/publish/QuickShot.exe) 단일 실행 파일 하나로 즉시 동작합니다.
   * USB나 외장 드라이브에 넣어 다른 PC에서도 설치 과정 없이 즉시 사용할 수 있습니다.
2. **시스템 트레이 상주 및 초경량 리소스 점유**:
   * 프로그램이 윈도우 우측 하단 작업 표시줄 트레이 영역에 상주하여 백그라운드에서 대기합니다.
   * 캡처 단축키(`Ctrl + Shift + A`)가 입력되는 순간에만 가상 캔버스를 활성화하여 시스템 자원을 극히 적게 소모합니다.
3. **다중 모니터(4대 등) 및 고DPI(125%, 150%) 1:1 완벽 정합**:
   * 모니터마다 해상도와 배율(100%, 125%, 150% 등)이 다른 환경에서도 마우스 커서 위치를 실시간 추적하여 해당 모니터 고유의 해상도와 1:1 픽셀 크기로 정밀 캡처합니다.
   * 다중 모니터 간 좌표 오프셋이나 배율 차이로 인한 화면 확대, 축소, 흐림, 픽셀 밀림 현상이 전혀 발생하지 않습니다.
4. **중복 실행 방지 (Single Instance)**:
   * 윈도우 전역 뮤텍스(`Mutex`)를 기반으로 단 하나의 인스턴스만 실행되도록 보장합니다. 이미 실행 중인 상태에서 다시 실행하면 기존 인스턴스가 유지됩니다.

## 2. 기본 사용 흐름 (Quick Workflow)

QuickShot은 불필요한 단계를 제거하고, 캡처부터 메신저/문서 붙여넣기까지 최단 동선으로 완료할 수 있도록 3단계 하이브리드 워크플로우를 제공합니다.

```text
[Ctrl + Shift + A]       [상단 바 모드 선택 및 캡처]           [즉시 Ctrl + V]
   단축키 입력    ───>   직사각형(드래그) / 창(클릭) /    ───>  메신저/문서에 바로 붙여넣기
                         현재화면(클릭) / 모든화면(클릭)       (주석이 필요 없는 경우)
                               │
                               ▼ (필요 시)
                         [주석 도구 작성]
                   (글자크기 12~40pt / 화살표 / 모자이크)
                               │
            ┌──────────────────┴──────────────────┐
            ▼                                     ▼
      [Ctrl + C 입력]                        [Enter 입력]
  (수정본 클립보드 복사 +              (수정본 클립보드 최종 갱신 +
   편집 창 열린 채 유지)               내 사진 폴더 자동 보관 후 종료)
```

1. **호출 (`Ctrl + Shift + A`)**:
   * 작업 중 언제든지 단축키를 누르면 현재 마우스 커서가 위치한 모니터 화면이 1:1 픽셀 그대로 동결되며, 화면 상단 중앙에 **Windows 11 스타일 플로팅 캡처 바**가 나타납니다.
2. **영역 선택 (4가지 방식 중 택1)**:
   * **직사각형**: 마우스 왼쪽 버튼을 누른 채 원하는 사각형 영역을 드래그합니다.
   * **창**: 캡처하고 싶은 윈도우 창 위로 마우스를 올리면 파란 테두리가 생기며, 좌클릭 1회로 해당 창 전체가 선택됩니다.
   * **현재 화면**: 상단 바에서 '현재 화면'을 누르면 활성 모니터 전체가 즉시 선택됩니다.
   * **모든 화면**: 상단 바에서 '모든 화면'을 누르면 4개 등 연결된 모든 모니터 전체 화면이 통째로 캡처되어 저장됩니다.
3. **1차 즉시 복사 (자동 완료)**:
   * **마우스 드래그를 놓거나 창/현재 화면을 클릭하는 순간, 해당 영역의 원본 이미지가 이미 클립보드에 복사**되어 있습니다.
   * 주석이 필요 없는 단순 캡처라면 바로 카카오톡, 슬랙, 노션, 메모장 등에서 `Ctrl + V`를 눌러 붙여넣을 수 있습니다.
4. **인라인 주석 편집 (필요 시)**:
   * 선택 영역 하단에 자동으로 뜨는 플로팅 툴바에서 텍스트(12~40pt), 모자이크, 화살표, 사각형, 형광펜을 선택해 화면 위에 직접 그립니다.
5. **편집 중 클립보드 복사 (`Ctrl + C`)**:
   * 주석을 작성하는 도중에 `Ctrl + C`를 누르면 창이 닫히지 않고 열린 상태를 유지하면서 **현재까지 수정한 내용이 포함된 합성 이미지가 클립보드에 즉시 갱신**됩니다.
6. **최종 완료 및 자동 파일 보관 (`Enter`)**:
   * 주석 작성이 완료된 후 `Enter` 키를 누르면, 최종 수정본이 클립보드에 복사됨과 동시에 **내 사진(`Pictures/QuickShot/`) 폴더에 타임스탬프 파일(`yyyyMMdd_HHmmss.png`)로 자동 저장**되고 캡처 창이 닫힙니다.

## 3. 상단 플로팅 캡처 바 및 4대 캡처 모드 완벽 가이드

QuickShot의 상단 캡처 바는 Windows 11 Snipping Tool의 심플함과 모던한 아크릴 디자인을 반영하여 제작되었습니다.

### 3.1 상단 바 특징 및 모드 자동 기억
* **스마트 위치 노출**: 사용자가 마우스를 둔 모니터의 상단 정중앙(`Top + 24px`)에 노출되어 시선의 분산 없이 바로 조작할 수 있습니다.
* **마지막 사용 모드 자동 기억 (`LastCaptureMode`)**: 직전에 선택했던 모드(예: 창 캡처 또는 직사각형 캡처)가 `%APPDATA%\QuickShot\settings.json`에 영구 보존되어, 다음번 호출 시에도 직전 모드가 기본 선택된 상태로 대기합니다.

### 3.2 4대 캡처 모드 상세

#### 1) 직사각형 캡처 (`Rectangle`)
* **동작**: 화면에서 마우스 좌클릭 후 대각선으로 드래그하여 임의의 사각형 영역을 지정합니다.
* **특징**: 마우스 버튼을 놓는 즉시 1차 클립보드 복사가 실행되며, 선택 박스 모서리와 변에 8개의 파란색 조절점(핸들)과 하단 인라인 주석 툴바가 나타납니다.

#### 2) 스마트 창 캡처 (`Window`)
* **동작**: 마우스를 이동하면 커서 아래에 있는 윈도우 창(브라우저, 탐색기, 실행 프로그램, 대화상자 등)을 실시간으로 감지하여 반투명 파란색 테두리로 하이라이트합니다. 원하는 창 위에서 **좌클릭 1회**를 누르면 창 전체가 오차 없이 1:1로 선택됩니다.
* **DWM Extended Frame Bounds 기술 적용**:
  * 일반적인 캡처 도구가 창 외곽의 보이지 않는 Aero Drop Shadow(투명 그림자, 약 7~8px)까지 잘못 캡처하는 문제를 해결했습니다.
  * Windows DWM API를 호출하여 그림자를 제외한 실제 1:1 시각적 창 경계만을 정밀 추출합니다.

#### 3) 현재 화면 캡처 (`FullScreen`)
* **동작**: 상단 바에서 [현재 화면] 버튼을 누르면 현재 마우스가 위치한 활성 모니터의 전체 해상도 영역이 1:1 픽셀 크기로 즉시 선택 박스로 확정됩니다.
* **특징**: 곧바로 1차 클립보드 복사가 완료되며, 전체 화면 위에 바로 인라인 텍스트나 모자이크 주석을 얹을 수 있습니다.

#### 4) 모든 화면 캡처 (`AllMonitors`)
* **동작**: 상단 바에서 [모든 화면] 버튼을 누르면, 현재 PC에 연결된 **모든 다중 모니터(예: 4대 모니터 전체)의 가상 데스크톱 전체 화면을 원클릭으로 통째로 캡처**합니다.
* **결과**: 4개 모니터의 전체 결합 이미지가 클립보드에 복사되고, 사진 자동 저장 폴더에 파일로 보관된 후 화면에 "모든 모니터 전체 화면이 클립보드에 복사 및 저장되었습니다" 토스트 알림을 띄우고 세션이 종료됩니다.

## 4. 인라인 주석 및 편집 도구 완벽 가이드

선택 영역이 확정되면 영역 하단에 자동으로 플로팅 주석 툴바가 나타납니다.

### 4.1 선택 영역 미세 조절 및 위치 이동
* **8방향 리사이즈 핸들**: 선택 박스의 네 모서리와 상하좌우 변 중앙에 위치한 파란색 사각형 조절점을 마우스로 드래그하여 캡처 영역의 크기를 1픽셀 단위로 미세하게 늘리거나 줄일 수 있습니다.
* **영역 전체 위치 이동**: 선택 영역 내부로 마우스를 이동하면 커서가 사방 화살표(`SizeAll`) 모양으로 변경됩니다. 이 상태에서 드래그하면 선택 박스의 크기를 유지한 채 캡처할 위치만 자유롭게 이동시킬 수 있습니다.

### 4.2 주석 도구 5종 상세 활용법

1. **사각형 (`Rectangle`)**:
   * 선택 영역 안에서 드래그하여 중요한 화면 요소나 버튼 둘레에 직사각형 강조 테두리를 그립니다.
2. **화살표 (`Arrow`)**:
   * 시작점에서 끝점으로 드래그하면 끝부분에 정밀한 화살촉이 달린 벡터 지시선이 생성됩니다. 특정 버튼이나 텍스트를 직관적으로 가리킬 때 사용합니다.
3. **텍스트 (`Text`)**:
   * 원하는 위치를 클릭하면 즉시 입력 글상자(TextBox)가 열립니다.
   * 한글/영문 설명을 타이핑한 후, **글상자 외부 영역을 클릭하면 텍스트가 화면에 영구 고정**됩니다.
   * **실시간 글자 크기 조절**: 텍스트를 입력하는 도중에도 툴바의 글자 크기 콤보박스에서 크기를 바꾸면 입력 중인 글상자의 크기가 실시간으로 반영됩니다.
4. **모자이크 (`Pixelate`)**:
   * 주민등록번호, 계좌번호, 전화번호, 비밀번호, 사내 대외비 문서 등 가려야 할 민감 영역을 마우스로 드래그합니다.
   * 드래그한 직사각형 영역의 원본 픽셀들이 즉시 **12px 단위의 격자형 블록 픽셀(깍두기 모자이크)**로 영구 비식별화 처리됩니다.
5. **형광펜 (`Highlighter`)**:
   * 중요한 텍스트 문구나 데이터 영역을 드래그하면, 배경 텍스트가 비치는 반투명(투명도 40%) 색상으로 밑줄을 긋듯이 부드럽게 강조합니다.

### 4.3 스타일 옵션
* **6색상 컬러 팔레트**: 빨강(`#FF0000`), 파랑(`#0080FF`), 초록(`#00CC00`), 노랑(`#FFFF00`), 검정(`#000000`), 흰색(`#FFFFFF`) 중 선택할 수 있습니다.
* **글자 크기 (폰트 크기) 6단계**:
  * `12pt (작게)`
  * `16pt (기본값)`
  * `20pt (보통)`
  * `24pt (크게)`
  * `32pt (매우 크게)`
  * `40pt (특대)`

### 4.4 실행 취소 (`Ctrl + Z`)
* 주석 작업 도중 실수로 잘못 그리거나 오타가 난 경우 `Ctrl + Z`를 누르거나 툴바의 [실행 취소] 버튼을 누르면, 가장 마지막에 추가한 주석 도형/텍스트/모자이크가 역순으로 하나씩 깔끔하게 제거됩니다.

## 5. 클립보드 동기화 및 저장 워크플로우

### 5.1 드래그 완료 즉시 1차 클립보드 복사
* 영역을 지정하는 순간, 원본 이미지가 시스템 클립보드에 무조건 1차 복사됩니다.
* 주석이 필요 없는 단순 캡처 작업 시에는 마우스를 떼자마자 바로 메신저 창에서 `Ctrl + V`만 누르면 되므로 소통 속도가 획기적으로 향상됩니다.

### 5.2 편집 중 무손실 클립보드 복사 (`Ctrl + C` - 옵션 B)
* 주석(텍스트, 화살표, 모자이크 등)을 그리고 있는 도중에 키보드에서 `Ctrl + C`를 누르면:
  * 텍스트 입력 상자 안에서 글자를 블록 지정한 상태라면 표준 텍스트 복사가 동작합니다.
  * 그 외 캔버스 상태에서는 **현재까지 그려진 모든 주석이 100% 래스터 합성(Baking)된 최신 수정본 이미지가 클립보드에 즉시 복사**됩니다.
  * **캡처 창은 닫히지 않고 열린 상태를 유지**하므로, 다른 메신저에 중간 시안을 붙여넣으면서 주석 작업을 계속 이어갈 수 있습니다.
  * 복사가 완료되면 화면 하단에 초록색 안내 토스트("수정본이 클립보드에 복사되었습니다")가 표시됩니다.

### 5.3 완료 및 자동 파일 보관 (`Enter`)
* 주석 작성을 모두 마치고 `Enter` 키를 누르거나 마우스 더블클릭을 실행하면:
  1. 최종 주석이 합성된 이미지가 클립보드에 최종 복사됩니다.
  2. 내 사진 폴더(`Pictures/QuickShot/`)에 타임스탬프 파일(`yyyyMMdd_HHmmss.png`)로 자동 영구 보관됩니다.
  3. 캡처 세션이 깔끔하게 종료됩니다.

### 5.4 다른 이름으로 파일 저장 (`Ctrl + S`)
* 자동 보관 폴더가 아닌 특정 프로젝트 폴더나 외장 디스크에 직접 이름을 붙여 저장하고 싶을 때는 `Ctrl + S`를 누릅니다.
* Windows 표준 [다른 이름으로 저장] 대화상자가 열리며 원하는 경로와 파일 형식(PNG, JPEG 등)을 지정해 저장할 수 있습니다.

### 5.5 단계별 세션 취소 (`ESC`)
* **1회 입력**: 선택한 사각형 영역 및 작성 중이던 주석을 모두 해제하고 상단 캡처 바로 복귀합니다.
* **2회 입력**: 캡처 세션을 완전히 종료하고 원래 작업 화면으로 복귀합니다.

## 6. 시스템 트레이 메뉴 및 환경설정 파일 상세 명세

### 6.1 시스템 트레이 우클릭 메뉴
윈도우 작업 표시줄 우측 알림 영역의 QuickShot 트레이 아이콘을 우클릭하면 다음 관리 메뉴가 제공됩니다:

* **화면 캡처 (Ctrl+Shift+A)**: 마우스 클릭으로 캡처 세션을 호출합니다. (아이콘을 좌클릭 더블클릭해도 동일)
* **모든 모니터 전체 캡처**: 4개 모니터 등 연결된 모든 화면 전체를 원클릭으로 즉시 캡처하여 클립보드 복사 및 저장합니다.
* **저장 폴더 열기**: 캡처 파일들이 자동 보관되는 로컬 디렉터리(`Pictures/QuickShot/`)를 윈도우 파일 탐색기로 엽니다.
* **Windows 시작 시 자동 실행**: PC 부팅 시 QuickShot이 백그라운드 트레이 모드로 자동 실행되도록 윈도우 레지스트리(`HKCU\Software\Microsoft\Windows\CurrentVersion\Run`)에 등록/해제합니다. (체크 토글 방식)
* **종료**: QuickShot 프로세스를 완전히 메모리에서 해제하고 종료합니다.

### 6.2 설정 파일 (`%APPDATA%\QuickShot\settings.json`) 명세
QuickShot은 사용자의 설정값을 사용자 프로필 디렉터리의 JSON 파일로 영구 보존합니다.

* **파일 경로**: `C:\Users\<사용자계정>\AppData\Roaming\QuickShot\settings.json`
* **JSON 구조 및 필드 설명**:

```json
{
  "HotkeyModifiers": "Control, Shift",
  "HotkeyKey": "A",
  "AutoSaveDirectory": "C:\\Users\\User\\Pictures\\QuickShot",
  "AutoSaveToFolder": true,
  "AutoCopyToClipboard": true,
  "RunOnStartup": false,
  "DefaultAnnotationColor": "#FF0000",
  "DefaultStrokeThickness": 3.0,
  "DefaultFontSize": 16.0,
  "LastCaptureMode": "Rectangle"
}
```

| 설정 키 | 타입 | 기본값 | 설명 |
|---|---|---|---|
| `HotkeyModifiers` | string | `"Control, Shift"` | 전역 캡처 호출 보조키 조합 |
| `HotkeyKey` | string | `"A"` | 전역 캡처 호출 주 키 (`A` ~ `Z`, `F1` ~ `F12` 등) |
| `AutoSaveDirectory` | string | `""` (공백 시 내 사진/QuickShot) | 캡처 이미지 자동 저장 폴더 경로 |
| `AutoSaveToFolder` | bool | `true` | `Enter` 시 로컬 파일 자동 저장 여부 (`false` 시 클립보드 복사만 수행) |
| `AutoCopyToClipboard` | bool | `true` | 드래그 완료 및 저장 시 클립보드 자동 복사 여부 |
| `RunOnStartup` | bool | `false` | 윈도우 부팅 시 백그라운드 자동 실행 여부 |
| `DefaultAnnotationColor` | string | `"#FF0000"` | 주석 도구 기본 시작 색상 (Hex 코드) |
| `DefaultStrokeThickness` | double | `3.0` | 사각형/화살표 기본 선 굵기 |
| `DefaultFontSize` | double | `16.0` | 텍스트 주석 기본 글자 크기 (pt 단위) |
| `LastCaptureMode` | string | `"Rectangle"` | 마지막으로 사용한 캡처 모드 (`Rectangle`, `Window`, `FullScreen`, `AllMonitors`) |

| **다른 이름으로 저장** | `Ctrl + S` | 원하는 폴더 및 파일명 지정 저장 대화상자 호출 |

| **크기 미세 조절** | 8방향 파란색 조절점 드래그 | 선택 박스 테두리 크기 1픽셀 단위 정밀 변경 |

## 8. 다중 모니터(4대) 실전 활용 팁 및 문제 해결 (FAQ)

### 8.1 다중 모니터 실전 활용 꿀팁
* **원하는 모니터에서 즉시 캡처하기**:
  * QuickShot은 캡처 단축키를 누르는 순간 **마우스 커서의 물리 좌표**를 읽어 들입니다.
  * 캡처하고 싶은 모니터 화면 위로 마우스를 휙 올려둔 뒤 `Ctrl + Shift + A`를 누르면, 그 모니터의 상단 중앙에 캡처 바가 즉시 뜹니다.
* **4개 모니터 전체 한 번에 보고서용으로 따기**:
  * 다중 모니터 작업 화면 전체를 한 장의 파노라마 이미지로 남기고 싶을 때는, 아무 곳에서나 `Ctrl + Shift + A`를 누르고 상단 바에서 **[모든 화면]**을 누르거나, 트레이 아이콘을 우클릭하여 **[모든 모니터 전체 캡처]**를 클릭하세요.

### 8.2 자주 묻는 질문 (FAQ) 및 문제 해결
**Q1. `Ctrl + Shift + A`를 눌러도 반응이 없습니다.**
* 다른 프로그램(예: 카카오톡 원격 캡처, 그래픽 소프트웨어, 게임 런처 등)이 동일한 단축키를 먼저 선점하고 있을 수 있습니다.
* 작업 표시줄 트레이 아이콘을 더블클릭하여 캡처를 실행하시거나, `%APPDATA%\QuickShot\settings.json`에서 `"HotkeyKey": "Q"` 또는 `"F1"` 등으로 변경 후 프로그램을 재시작하세요.

**Q2. 디스크에 파일 저장 없이 클립보드 복사만 사용하고 싶습니다.**
* `%APPDATA%\QuickShot\settings.json` 파일을 메모장으로 열고 `"AutoSaveToFolder": false`로 수정한 뒤 저장하세요. 이후부터는 파일 생성 없이 순수 클립보드 복사 전용 모드로 동작합니다.

**Q3. 자동 저장 파일명이 중복되면 덮어쓰기되나요?**
* 아닙니다. QuickShot은 `yyyyMMdd_HHmmss.png` 형식을 사용하며, 같은 초 단위에 연속으로 저장하더라도 `_1.png`, `_2.png` 형태로 자동 넘버링되어 기존 캡처본을 안전하게 보존합니다.
