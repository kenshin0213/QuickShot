# QuickShot

Windows 10/11 환경을 위한 초고속 화면 캡처 및 즉석 인라인 주석 도구입니다.

복잡한 창 이동이나 외부 편집 프로그램 호출 없이, 단축키(`Ctrl + Shift + A`) 하나로 화면을 1:1 무왜곡 동결하고 즉석에서 텍스트·모자이크·화살표를 작성하여 메신저와 문서에 즉시 붙여넣을 수 있습니다.

---

## 주요 기능 및 특징

1. **무설치 단일 실행 파일 (Self-Contained)**:
   * 복잡한 설치 과정이나 외부 .NET 런타임 설치 없이 단일 실행 파일 하나로 즉시 동작합니다.
2. **다중 모니터 및 고DPI(125%, 150%) 1:1 완벽 정합**:
   * 모니터마다 해상도와 배율이 다른 환경에서도 마우스 커서 위치를 실시간 추적하여 Win32 `SetWindowPos` 기반 물리 픽셀로 1:1 정밀 밀착합니다.
   * 다중 모니터 간 화면 확대, 축소, 흐림, 픽셀 밀림 왜곡이 전혀 발생하지 않습니다.
3. **Windows 11 스타일 상단 플로팅 캡처 바**:
   * **직사각형 (`Rectangle`)**: 마우스 드래그로 원하는 사각형 영역 지정.
   * **스마트 창 (`Window`)**: DWM 그림자 없는 1:1 창 경계 자동 감지 및 원클릭 캡처.
   * **현재 화면 (`FullScreen`)**: 활성 모니터 전체 화면 1:1 캡처.
   * **모든 화면 (`AllMonitors`)**: 연결된 모든 모니터 전체 화면 통째로 원클릭 캡처 및 저장.
   * 마지막으로 사용한 캡처 모드를 기억하여 다음 실행 시 기본 모드로 대기.
4. **인라인 주석 및 편집 도구 5종**:
   * **텍스트**: 원하는 위치에 클릭하여 한글/영문 입력, 실시간 글자 크기 6단계(`12pt` ~ `40pt`) 조절.
   * **모자이크**: 개인정보, 계좌번호 등 민감 영역 12px 격자 비식별화(깍두기 모자이크).
   * **화살표 / 사각형 / 형광펜**: 6색상 팔레트 지원 벡터 강조선 및 밑줄.
   * **`Ctrl + Z`**: 실수로 그린 주석 1단계씩 역순 실행 취소.
5. **2단계 클립보드 & 저장 워크플로우**:
   * **1차 즉시 복사**: 영역 지정 즉시 원본 이미지가 클립보드에 자동 복사 (`Ctrl + V` 즉시 사용 가능).
   * **편집 중 복사 (`Ctrl + C`)**: 주석 작성 중 창을 닫지 않고 수정본을 클립보드에 즉시 갱신 (편집 유지).
   * **완료 및 자동 보관 (`Enter`)**: 수정본 최종 복사 + `Pictures/QuickShot/` 폴더에 타임스탬프(`yyyyMMdd_HHmmss.png`) 파일 자동 보관 후 종료.

## 단축키 및 조작 일람표

| 기능 | 조작 방법 / 키 | 실행 결과 |
|---|---|---|
| **캡처 호출** | `Ctrl + Shift + A` | 마우스 위치 모니터 화면 동결 및 상단 캡처 바 표시 |
| **트레이 호출** | 트레이 아이콘 더블클릭 | 단축키와 동일하게 캡처 세션 호출 |
| **직사각형 캡처** | 마우스 좌클릭 드래그 | 사각형 영역 지정 (마우스 뗄 때 1차 클립보드 자동 복사) |
| **스마트 창 캡처** | 창 호버 후 좌클릭 1회 | DWM 기반 그림자 없는 1:1 창 감지 및 원클릭 캡처 |
| **현재 화면 캡처** | 상단 바 [현재 화면] 클릭 | 현재 활성 모니터 전체 화면 1:1 영역 확정 |
| **모든 화면 캡처** | 상단 바 [모든 화면] 클릭 | 모든 모니터 전체 가상 화면 원클릭 통째 캡처 & 보관 |
| **수정본 복사 (창 유지)** | `Ctrl + C` | 현재까지 작성한 주석 합성 이미지를 클립보드에 복사 |
| **완료 및 저장** | `Enter` 또는 더블클릭 | 최종본 클립보드 복사 + 파일 자동 저장 후 종료 |
| **다른 이름으로 저장** | `Ctrl + S` | 원하는 경로 및 파일명 지정 저장 대화상자 호출 |
| **실행 취소** | `Ctrl + Z` | 마지막으로 추가한 주석 1단계씩 역순 취소 |
| **단계별 취소** | `ESC` | 1회: 선택 영역 해제(상단 바로 복귀), 2회: 캡처 세션 종료 |

## 빌드 및 배포

### 요구 사항
* Windows 10 (1809+) 또는 Windows 11
* .NET 8.0 SDK (Windows Desktop Workload)

### 빌드 및 테스트
```bash
# 솔루션 빌드
dotnet build QuickShot.sln -c Release

# 단위 테스트 실행
dotnet test tests/QuickShot.Tests/QuickShot.Tests.csproj
```

### 무설치 단일 실행 파일 배포
```bash
dotnet publish src/QuickShot/QuickShot.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -o publish
```
빌드 완료 후 `publish/QuickShot.exe` 단일 파일을 실행하면 외부 의존성 없이 즉시 시스템 트레이 모드로 상주합니다.
