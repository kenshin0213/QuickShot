# Shell Templates

셸 실행이 장기화되거나 실패할 때만 이 문서를 읽는다.

## 1. 실행 전 확인

실행 전에 다음을 확인한다.

- 현재 런타임의 셸 도구와 지원 타임아웃
- 명령의 예상 실행 시간
- 출력 파일과 프로세스의 변경 범위
- 취소·타임아웃 시 자식 프로세스 정리 방법

도구명이 다른 환경에서는 동일한 능력의 도구로 대체하며, 존재하지 않는 특정 호출명을 필수 조건으로 만들지 않는다.

## 2. PowerShell 격리 실행 예시

```powershell
powershell.exe -NoProfile -NonInteractive -Command '& { <COMMAND>; exit $LASTEXITCODE }'
```

`<COMMAND>`를 실제 명령으로 바꾼다. 작은따옴표는 호출 셸이 `$LASTEXITCODE`를 미리 확장하지 못하게 한다. 실제 타임아웃은 현재 셸 도구가 제공하는 설정을 우선 사용한다.

## 3. 장기 실행 명령

장기 실행이 필요한 경우:

1. 작업 성격에 맞는 최대 실행 시간을 지정한다.
2. 정상 완료 신호와 실패 신호를 정의한다.
3. 무출력만으로 hang으로 판정하지 않고 CPU·프로세스 상태 또는 완료 신호를 함께 확인한다.
4. 타임아웃 시 프로세스 그룹과 생성된 임시 파일을 정리한다.

## 4. 오류 보고 형식

명령이 취소·타임아웃·실패하면 사용자 응답에 다음 정보를 포함한다.

```text
[명령어 실행 중단 및 오류 보고]
- 실행 명령어: <COMMAND>
- 실행 상태: 실패 (취소 / 타임아웃 / 세션 오류 / 종료 코드)
- 중단 원인: <CAUSE>
- 영향 및 후속 조치: <ACTION>
```

셸 도구가 반환한 원문 로그는 가능한 한 보존하고, 에이전트가 추가한 해석은 원문과 분리한다.
