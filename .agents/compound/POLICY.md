# Compound Engineering Policy

작업 중 발견한 재사용 가능한 교훈을 기록하고 승격하는 기준을 정의한다.

## 1. Lesson 기록 기준

다음 조건을 모두 만족하면 lesson 후보로 제안한다. 정책 파일 기록은 사용자가 승인한 산출물 범위에 포함될 때만 수행한다.

- **반복성**: 동일한 문제 또는 패턴이 2회 이상 발생
- **비자명성**: 에이전트의 기본 행동만으로 해결되지 않는 프로젝트 고유 지식
- **재사용 가치**: 향후 유사 작업의 시행착오를 줄일 수 있음

## 2. Lesson 기록 형식

```markdown
## LESSON-{NNN}: {한국어 제목}

- **발견일**: YYYY-MM-DD
- **컨텍스트**: 어떤 작업 중 발견했는지
- **문제**: 겪은 문제 또는 비효율
- **해결**: 적용한 해결 방법
- **일반화**: 다른 상황에 적용 가능한 원칙
- **참조**: 관련 파일, 커밋, 대화 ID
```

## 3. 승격 절차

| 단계 | 조건 | 행동 |
|---|---|---|
| 기록 | lesson 기준 충족 | 이 파일 하단 카탈로그에 추가 |
| 검증 | 서로 다른 작업에서 2회 이상 재적용 성공 | `검증됨` 태그 부여 |
| 승격 | 프로젝트 전반에 적용 가능 | 공통 또는 프로젝트 지침에 규칙으로 편입 |
| 폐기 | 6개월 이상 미참조 또는 환경 변경으로 무효화 | `폐기` 태그 부여 후 접기 |

## 4. Lesson 카탈로그

아직 기록된 lesson 없음.
